# 日本語理解モデル研究

このフォルダは、Rakukan の長文変換、文節分解、候補生成を再検討するための日本語理解モデル研究をまとめる場所です。

## ドキュメント

- [日本語入力エンジンのための日本語理解モデル](JAPANESE_UNDERSTANDING_FOR_IME.md)

## 位置づけ

この研究は、すぐに変換ロジックを改修するための実装計画ではありません。

目的は、以下の論点を理解し、Rakukan の設計判断に使える形へ整理することです。

- 日本語の形態素解析はどこまでできるか。
- IME に必要な日本語文法とは何か。
- ひらがな列や音声列から意味をどう組み立てるか。
- azooKey がどのように実用的な品質を確保しているか。
- Rakukan が文節分解へ進む場合、どの順序で研究・検証すべきか。

安易な文字数分割や句読点分割ではなく、辞書、品詞、接続コスト、候補経路、学習、候補契約を含めた変換理論として扱います。
